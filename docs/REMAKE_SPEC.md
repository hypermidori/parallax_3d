# OUTER PARALLAX FIELD — NIGHT VECTOR

現在の制作対象はブラウザで動く奥行き方向のレールシューティングの1ステージ試作。
元ゲームは `C:/workspace/codex_sample`。このワークスペースに独立したリメイクを作る。
サブエージェントは使用しない。

## 決定済み

- 元ゲームを実際に起動して確認した、青黒い夜の市街地を継承する。
- 背景は画像生成したコンセプトを基準にBlender CLIで制作し、テクスチャ付きGLBをゲームで描画する。
- 一本操作：照準へ主人公が追従する。通常射撃は自動、押してロックを蓄積、離してレーザー。
- マウス、タッチ、ゲームパッドを同一の操作モデルに接続する。
- 主人公は2Dドット絵。移動・旋回・推進に対応したフレームアニメーションを使う。
- 約2分の道中＋緑色の歩行戦車ボス（合計約2〜3分）、被弾、ゲームオーバー、クリア、リトライを実装する。

## 美術の基準

コンセプト：`references/city/night-boulevard-concept-v01.png`。
元の実機画像：`screenshots/source-stage1.png`。

主要な再現対象：
1. 青黒い夜空と冷たい青の遠景の霞。
2. 高密度の窓、白と淡い青の点灯、一部の暖色の窓と少量の紫。
3. 低層の重い基壇、段差のある高層部、窓のフレーム、屋上設備。
4. 道路をまたぐガラスの連絡橋と、下面のトラス・支持柱。
5. 摩耗した路面、車線、側溝、縁石、細いサービス灯。
6. 左右と前後で明確なパララックス。背景は実際の立体としてルートから確認する。

## 検証

- BlenderからGLBを書き出し、メッシュ、UV、画像テクスチャ、材質を確認する。
- ブラウザでコンセプトに近いカメラ位置から比較し、必要な形状・照明を修正する。
- 通常操作、ロックと解放、被弾、ポーズ、クリア、再開、タッチ入力を確認する。
- 性能値は計測したブラウザ環境の値として記録し、スマホ実機の速度と混同しない。

## 元ゲームから利用するもの

主人公の元スプライト、路面・歩道テクスチャ、Stage 1のBGM・ボスBGMと一部効果音。
新規生成画像とBlenderの制作スクリプトはこのプロジェクトに保存する。
