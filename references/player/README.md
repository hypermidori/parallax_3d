## 今回の補完・仮決め

顔、前髪の正面形状、紫の瞳、閉じた襟と前面装甲、側面の奥行きは元画像に描かれていないため今回の提案です。
資料 `docs/STORY_AND_STAGE_SETTING.md` にある「P.A.T.H.O.S運用特化型アンドロイド」「感情の均衡」という設定を表情の方向性に反映しています。名前や新たな能力設定は追加していません。

元画像はホバリング中のアニメーションなので、片脚が曲がっています。三面図では形を読みやすい左右の足が接地した姿勢に整理しました。ゲーム内のホバリング姿勢は別に作ります。

## 3D化時の注意

この画像はデザイン初稿であり、厳密な製図ではありません。3方向の輪郭・装甲位置はモデリング時に整合させます。側面の腕は正背面より下がっているので、基準ポーズを低いAポーズへ揃えます。

生成画像の腰ブースター先端は尖った形になっています。元のスプライトの噴射表現を優先し、3Dでは開口のあるノズルとして整理し、紫の炎を別のエフェクト部品にします。
髪の下で隠れる背面装甲は、背中の発光ユニットがゲーム視点で見えるよう奥行きと毛束を調整します。

制作目安は本体・髪・装備合計3,000〜6,000三角形、1024px程度のペイントテクスチャです。これはPS2の一律仕様ではなく今回の目標です。
ボルト、細い装甲線、陰影は主にテクスチャで表現し、髪・顔・武装・腰ユニットのシルエットにメッシュを配分します。
可動関節、髪・腰装甲の揺れ、噴射エフェクトは別段階として検証します。

この三面図の承認後、3D試作も制作しました。モデルの仕様と確認方法は `PROTOTYPE.md` を参照してください。ゲームへの組み込みは別段階です。
